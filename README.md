## 🚀 Flagship Project — WatoBot

<div align="center">

[![WatoBot](https://img.shields.io/badge/WatoBot%20Cloud%20Platform-Live%20%26%20Operational-25D366?style=for-the-badge&logo=whatsapp&logoColor=white)](https://mudbot-erai.onrender.com)
[![Render](https://img.shields.io/badge/Hosted%20on-Render.com-46E3B7?style=for-the-badge&logo=render&logoColor=black)](https://mudbot-erai.onrender.com)
[![Docs](https://img.shields.io/badge/Handover%20Docs-20%20Page%20PDF-red?style=for-the-badge&logo=adobeacrobatreader&logoColor=white)](https://github.com/sibiabi123/mudbot/blob/main/WatoBot_Project_Handover_Document.pdf)

</div>

> **WatoBot** is a self-hosted, cloud-native **24/7 WhatsApp automation microservice** that runs on Render.com PaaS (Singapore). Link your personal WhatsApp via QR code and automate scheduled messages, broadcasts to full-sized groups, and REST API triggers — without Meta API approvals, per-message fees, or keeping your laptop on.

| 🌟 Feature | Details |
| :--- | :--- |
| 🤖 **24/7 Autonomous** | Cloud cron engine sends scheduled messages even if your phone is off |
| 🔒 **Zero-Knowledge AES-256** | Sessions encrypted client-side — server owner cannot read your data |
| 👥 **Full Group Support** | Works with full-sized WhatsApp groups (unlike Meta WABA 8-member cap) |
| ⚡ **REST API** | Trigger WhatsApp messages from Python, Node.js, or cURL |
| 🌐 **Live Now** | [mudbot-erai.onrender.com](https://mudbot-erai.onrender.com) |
