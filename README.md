## 📐 WatoBot — Message Scheduling Sequence (System Interaction)

```mermaid
sequenceDiagram
    autonumber
    actor User as 👤 User Browser
    participant GW as ⚡ Fastify Gateway
    participant Auth as 🔐 Auth Middleware
    participant Cron as ⏰ GNU Cron Daemon
    participant Crypto as 🔒 AES-256 Crypto
    participant Mudslide as 🤖 Mudslide Engine
    participant WA as 📡 WhatsApp Servers

    User->>GW: POST /api/register { phone, name }
    GW->>Auth: Generate 256-bit hex token
    Auth-->>User: { token, userDir, redirectUrl }
    User->>User: Store token in localStorage

    User->>GW: POST /api/connect (Bearer token)
    GW->>Auth: SHA-256² token verification
    Auth->>Mudslide: Spawn mudslide login process
    Mudslide->>WA: Initiate Multi-Device pairing WSS
    WA-->>Mudslide: Stream QR Code bytes (Unicode blocks)
    Mudslide-->>User: QR Code rendered on verify.html

    User->>WA: 📱 Scan QR with WhatsApp mobile app
    WA->>Mudslide: Session authenticated → creds.json
    Mudslide->>Crypto: AES-256-CBC encrypt(creds.json, token)
    Crypto->>Crypto: Write .mudslide.enc to disk

    User->>GW: POST /api/schedule { message, cron, recipients }
    GW->>Cron: Write crontab entry → run-schedule.js
    Note over Cron: Waits for cron trigger...

    Cron->>GW: POST /api/message (127.0.0.1:3000)
    GW->>Crypto: AES-256-CBC decrypt .mudslide.enc → /tmp
    Crypto-->>GW: Decrypted session available
    GW->>Mudslide: mudslide send --to {recipients} --text {msg}
    Mudslide->>WA: TLS WebSocket send (Multi-Device)
    WA-->>Mudslide: ✅ Message delivered
    Mudslide->>Crypto: Re-encrypt session → wipe /tmp
    Crypto-->>User: 200 OK { status: "sent" }
```
