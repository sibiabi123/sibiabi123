## 🚀 Flagship Project — WatoBot Cloud Platform

<div align="center">

[![WatoBot Banner](https://img.shields.io/badge/WatoBot-24%2F7%20Cloud%20WhatsApp%20Automation-006d2f?style=for-the-badge&logo=whatsapp&logoColor=white)](https://mudbot-erai.onrender.com)
[![Render Live](https://img.shields.io/badge/Hosted%20on-Render.com%20(Singapore)-46E3B7?style=for-the-badge&logo=render&logoColor=black)](https://mudbot-erai.onrender.com)
[![Handover Documentation](https://img.shields.io/badge/Handover%20Docs-20%20Page%20PDF-red?style=for-the-badge&logo=adobeacrobatreader&logoColor=white)](https://github.com/sibiabi123/mudbot/blob/main/WatoBot_Project_Handover_Document.pdf)

</div>

> **WatoBot** is an enterprise-grade cloud automation platform deployed on Render.com PaaS. It enables autonomous, scheduled, and API-triggered WhatsApp messaging across individuals and full-sized groups with client-side AES-256 encryption.

```
  ┌─────────────────┐       HTTPS       ┌──────────────────────────────┐       TLS WSS       ┌─────────────────────────┐
  │  Client Web UI  │ ────────────────► │  Fastify Gateway (Port 3000) │ ──────────────────► │  WhatsApp Edge Servers  │
  │  (localStorage) │                   │  + Linux GNU Cron Subsystem  │                     │  (Multi-Device Protocol)│
  └─────────────────┘                   └──────────────────────────────┘                     └─────────────────────────┘
                                                       ▲
                                                       │ 5-Minute Heartbeat
                                        ┌──────────────────────────────┐
                                        │  UptimeRobot Global Watchdog │ (Keeps 24/7 Live)
                                        └──────────────────────────────┘
```

| Key Feature | Specification |
| :--- | :--- |
| 🤖 **Autonomous Cron Scheduling** | Sends messages even when your computer and phone are turned off |
| 🔒 **Zero-Knowledge Encryption** | AES-256-CBC with SHA-256 key derivation — zero server access |
| 👥 **WhatsApp Group Broadcasts** | Full-sized groups supported with zero Meta restrictions |
| ⚡ **Instant Authentication** | Direct 256-bit token handshake (<10ms onboarding) |
| 🌐 **Live URL** | [mudbot-erai.onrender.com](https://mudbot-erai.onrender.com) |
